# Profile pictures

Player pictures are stored here as normal image files. Clan pictures belong in `clans/`.

To replace a picture, upload the replacement using the same filename and image format. Keep filenames lowercase. `index.html` maps player names to these paths and gives custom pictures priority over YouTube pictures. JDK and DJJDK share `djjdk.jpg`.

For names containing spaces or punctuation, filenames use safe hyphenated names. Check the mappings in `index.html` before replacing a file. Changing a filename or image format also requires updating its mapping.

Copy this folder together with `index.html` when moving or downloading the site. Pictures load from this repository and do not depend on the original YouTube image URLs.
